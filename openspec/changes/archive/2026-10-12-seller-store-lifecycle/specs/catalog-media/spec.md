## MODIFIED Requirements

### Requirement: No deletion of stored images by API operations
Операции API категорий и товаров (создание, изменение, удаление) SHALL NOT
удалять объекты из MinIO. Единственное исключение — окончательное удаление
магазина (STORE_PURGED): объект изображения товара удаляемого магазина SHALL
удаляться из бакета `products`, только если ни один товар другого магазина
не содержит изображения с тем же hash. Отсутствие объекта при удалении SHALL
NOT быть ошибкой. Бакет `categories` SHALL NOT затрагиваться.

#### Scenario: Удаление товара
- **WHEN** удаляется товар с изображениями через `DELETE /products/{id}`
- **THEN** объекты изображений остаются в бакете `products`

#### Scenario: Изображение только удаляемого магазина
- **WHEN** обрабатывается STORE_PURGED, и изображение используют только товары этого магазина
- **THEN** объект удаляется из бакета `products`

#### Scenario: Общее изображение
- **WHEN** обрабатывается STORE_PURGED, и изображение с тем же hash есть у товара другого магазина
- **THEN** объект остается в бакете

**Observation**: OBS-05, OBS-06
